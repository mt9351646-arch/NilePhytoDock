# Installation — NilePhytoDock Studio v1.0.0

Download and run `NilePhytoDock-v1.0.0-Setup.exe`. Python, Qt, Java, P2Rank, Smina and the scientific libraries install automatically.

See [the current English guide](Release_v1.0.0_EN.md) for installation, workflow, output folders and uninstall instructions. Documentation is external to the application.
