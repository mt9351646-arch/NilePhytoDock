# Troubleshooting — 0.6.0

If the old icon/version appears, open the versioned 0.6 shortcut. Preserve the whole portable directory. Check Settings and process logs when an engine is unavailable. Select a predicted pocket for every target before automatic screening. Review structure status and source eligibility when a profile has no ready ligands. A blank oil index may be correct for HPLC, headspace, duplicate identities or incomplete results. Geometry mismatches must be repaired by inspecting source files and reanalysis, never by moving a plotted endpoint. Keep source, prepared structures, pose files and project snapshot together when reopening a study.

Docking scores and oil indices are computational screening priorities. They do not establish affinity, potency, efficacy, safety or mixture synergy. GC peak area is not an absolute mass fraction. Preparation uses a general protonation approximation, does not rebuild missing loops or side chains, and does not enumerate a pH-dependent ligand ensemble. One BEN/3PTB redocking system is not broad validation. Windows 11 on the current host is tested; Windows 10, a clean VM and all GPU configurations are untested. The executable is unsigned. PyMOL is optional and is not bundled.
